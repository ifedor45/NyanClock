##ENGLISH
# 🕰️ Digital Hanging Clock Slideshow (Nyan Cat Edition)

Well, what can I say... A clock with a NyanCat GIF. I know you've been waiting for this (not really).  
Just run the `.exe` and it works. Feel free to dig into the source code, though it probably won't help much.

**Version:** 1.0.5

## 🎮 Features
-   **Draggable:** Move the window by clicking and dragging anywhere.
-   **Close:** Double-click the clock OR close the black console window.
-   **Animation:** Automatically cycles through `rope*.gif` files.

## 🛠️ For Developers (Source Code)
Want to run from source with your own GIFs?
1.  Run `clock.py` (renamed for convenience).
2.  Drop your GIFs into the folder and rename them following the pattern: `rope1.gif`, `rope2.gif` ... `rope50.gif`.

## 📦 Requirements
-   Python 3.12+
-   Libraries: `tkinter` (built-in), `Pillow`

## ⚡ Installation & Run
```bash
py -3.12 -m pip install Pillow
python clock.py

```
